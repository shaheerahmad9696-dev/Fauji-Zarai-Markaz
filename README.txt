FAUJI ZARAI MARKAZ - STREAMLIT WEBSITE

1. Put app.py and the image files in your E:\Fauji-Zarai-Markaz folder.
2. Keep your existing logo.png and shop.png there.
3. Run:
   python -m streamlit run app.py

The navigation buttons are functional.
The code uses:
- potexin.png
- bag.png
- dap.png
- product4.png, product5.png, product6.png (if you have them)
- logo.png
- shop.png

Replace any placeholder product images with your real company product images.
